v1.0 初始版本 · 单用户本地版 最初版本

一切从这里开始。一个可以在电脑和平板上使用的网页应用，支持基础的生活管理功能。

核心功能
  • 待办清单：支持添加、完成、删除，按分类和优先级管理
  • 计时器：倒计时模式，实时显示天/时/分/秒
  • 目标管理：设置目标、进度条、截止日期
  • 倒数日：记录重要日期，支持"距今还有"和"已经过了"
技术实现
  • Node.js + Express 后端
  • 纯前端 HTML/CSS/JS，无需安装
  • 本地数据存储（localStorage）
  • 支持手机、平板、电脑多设备访问
v1.1 功能扩展 · 统计与日记 第一次功能升级

根据使用反馈，增加正向计时、统计面板和日记功能，让应用更全面。

新增功能
  • 正向计时器：除了倒计时，新增正向计时模式（记录坚持了多少天）
  • 统计面板：按日/周/月/年四个维度查看数据
  • 统计卡片：待办总数、已完成、待完成、完成率
  • 分类统计：按工作/生活/学习/其他分类查看分布
  • 优先级分布：高/中/低优先级的数量占比
  • 目标概览：已完成数、总数、平均进度
  • 日记功能：写日记、选心情 emoji、日记预览
体验优化
  • 计时器新增颜色自定义
  • 倒数日支持自定义 emoji
  • 底部导航栏优化，更方便切换
v2.0 多用户系统 · 数据隔离与保密柜 重大版本升级

从单用户升级为多用户系统，支持多人使用。加入保密柜功能，私密内容端到端加密，管理员也无法查看。

多用户系统
  • 用户注册与登录系统（用户名 + 密码）
  • JWT 令牌身份认证
  • 每个用户数据完全隔离，互不可见
  • MongoDB 云数据库存储，数据自动同步
  • 第一个注册的用户自动成为管理员
保密柜（端到端加密）
  • 独立的保密柜密码（与登录密码分开）
  • AES-256 浏览器端加密，服务器只存密文
  • 支持加密存储日记、待办、便签
  • 管理员也无法解密保密柜内容
  • 保密柜可重置（需登录密码验证，重置后内容清空）
管理后台
  • 总用户数、今日/本周/本月活跃用户统计
  • 今日/本周新增用户数
  • 用户列表：用户名、活跃状态、注册时间
  • 管理员可重置用户密码
安全升级
  • 密码使用 bcrypt 哈希 + 盐值存储
  • HTTPS 加密传输
  • 所有 API 请求需身份验证
  • 越权访问自动拦截
v2.1 密码找回 · 密保问题 账号安全增强

增加密保问题机制，用户忘记密码时可以自助找回，不需要联系管理员。

新增功能
  • 注册时必须设置密保问题和答案（5 个预设问题可选）
  • 登录页新增"忘记密码？"入口
  • 自助找回密码：输入用户名 → 显示密保问题 → 回答正确 → 设置新密码
  • 密保答案同样使用 bcrypt 哈希存储，保护隐私
后端支持
  • 新增密保问题查询接口
  • 新增密码重置接口（需验证密保答案）
  • 安全限制：密保答案错误次数过多需稍后再试
v2.2 密码确认 · 防止手误 体验优化

注册和重置密码时增加二次确认（输入两遍密码），避免因为手误输错密码导致登录不上。

注册流程
  • 新增"确认密码"输入框（注册模式下显示）
  • 两次密码不一致时提示错误，不让提交
  • 错误提示清晰明确，引导用户重新输入
密码重置流程
  • 通过密保找回密码时，新密码也需要输入两遍确认
  • 保密柜设置密码时同样需要两遍确认
  • 所有涉及设置密码的场景统一加了确认机制
v2.3 管理员批准重置 · 完善密码找回 流程优化

当用户连密保问题也忘了时，可以向管理员发送重置请求。管理员批准后用户自行设置新密码，保护隐私同时解决问题。

用户侧
  • 找回密码页面底部新增"密保也忘了？找管理员重置"按钮
  • 点击后向管理员发送重置请求（同一用户不能重复提交）
  • 请求发送后显示"已向管理员发送重置请求"提示
  • 管理员批准后，用户重新进入找回密码可直接设置新密码（无需密保答案）
  • 显示"管理员已批准你的重置请求"绿色提示
管理员侧
  • 管理后台新增"密码重置请求"区块
  • 列出所有待处理的请求（用户名 + 提交时间）
  • 点击"批准重置"一键同意
  • 批准后请求自动标记为已处理，从列表消失
  • 管理员不需要知道用户新密码，保护用户隐私
后端数据
  • 新增 ResetRequest 模型，记录所有重置请求
  • 用户表新增 resetApproved 字段，标记批准状态
  • 用户设置新密码后自动清除批准状态
v2.4 待办归档 · 统计与清单分离 体验升级

解决"删除已完成待办导致统计数据消失"的痛点。已完成的待办删除后自动归档，清单变清爽但历史统计数据完整保留。同时优化管理员后台用户排序。

待办归档机制
  • 已完成的待办删除 → 自动标记为"已归档"（不是真删）
  • 未完成的待办删除 → 直接删除（没完成过不影响统计）
  • 待办清单只显示未归档的任务，保持清爽
  • 待办进度条只统计当前清单内的任务
统计优化
  • 统计包含已归档的已完成待办，周/月/年数据不丢失
  • "已完成"按完成时间（completedAt）判断，而非创建时间
  • 哪天完成的就算哪天的统计，数据更准确
  • 统计区间内创建 OR 完成的待办都计入总数
  • 完成率计算更科学合理
管理员后台优化
  • 用户列表按最后活跃时间倒序排列（最近上线的排最上面）
  • 显示"上次活跃：今天/昨天/3天前"等相对时间
  • 一眼就能看到哪些用户最近在用
v2.5 管理员权限分级 · 超级管理员机制 权限体系升级

引入超级管理员与普通管理员两级权限。超级管理员可以设置或取消其他用户的管理员权限，普通管理员只能处理密码重置。权限实时生效，无需重新登录。

权限分级
  • 超级管理员：第一个注册的用户，拥有全部权限
  • 普通管理员：可查看后台、批准密码重置，但不能设置其他管理员
  • 超级管理员不能被取消权限（防止锁死）
  • 普通管理员可被超级管理员随时取消
后台界面优化
  • 用户列表从单行排列改为卡片式布局
  • 每张卡片显示：头像、用户名、角色标签、活跃状态
  • 角色标签三色区分：超级管理员（橙）、管理员（蓝）、普通用户（灰）
  • 操作按钮分行排列：批准重置 + 设为/取消管理员
后端改进
  • auth 中间件改为每次请求实时查数据库获取最新权限
  • 权限变更后即时生效，不依赖 JWT token 里的旧值
  • 服务器启动时自动迁移：第一个用户升级为超级管理员
  • 新增 POST /api/admin/set-admin 接口（仅超级管理员可调用）
v2.6 性能优化 · 移除主题切换 性能修复

登录页面严重卡顿，经排查是主题切换功能导致。移除多主题切换及相关 CSS/JS，恢复单一靛蓝主题，保留管理员权限功能。

移除内容
  • 移除 6 套多主题 CSS 变量定义（莫兰迪/海洋/日落/森林/玫瑰）
  • 移除登录页主题预览圆点选择器
  • 移除顶栏主题切换按钮和主题面板
  • 移除 app.js 中主题状态、applyTheme 函数及相关事件监听
  • 移除 server.js 中主题数据存储字段和 POST /api/theme 接口
保留内容
  • 单一靛蓝主题（#6366f1）保持统一视觉风格
  • 管理员权限分级功能完整保留
  • 所有其他功能不受影响
v2.7 界面精简 · 底部导航 8→5 + 图标子导航 交互重构

底部导航栏从 8 个缩减到 5 个，合并同类功能。目标与倒数日、日记与保密柜通过页面内图标按钮切换。管理后台入口从底部移到顶栏齿轮图标。

底部导航精简
  • 从 8 个标签精简为 5 个：待办 / 计时 / 目标 / 日记 / 统计
  • 管理后台从底部导航移至顶栏右上角齿轮图标
  • 普通用户底部固定 5 个，界面更清爽
  • 管理员点齿轮图标进入管理后台
页面内图标子导航
  • 目标页：顶部两个大图标按钮 → 🎯目标 / 📅倒数日
  • 日记页：顶部两个大图标按钮 → 📖日记 / 🔒保密柜
  • 点击图标即时切换内容区域，保留各自功能
  • 子导航按钮选中时高亮，清晰指示当前位置
顶栏改造
  • 顶栏右侧新增齿轮图标按钮（仅管理员可见）
  • 齿轮按钮与退出按钮并排排列
  • 非管理员看不到齿轮，界面更干净
  • 点击齿轮直接跳转管理后台页面
v2.8 可展开统计 · 时间分组详情 交互升级

统计页面从单调的数字升级为可交互的详情面板。点击数字卡片展开查看每条记录的内容和时间，按时间范围自动分组：周内按日、月内按周、年内按月，层次清晰一目了然。

可展开统计卡片
  • "待办总数""已完成""待完成"三个卡片可点击展开详情
  • 日记统计行也可点击展开查看日记列表
  • 展开后显示每条记录的内容和具体时间
  • 待办记录带状态标记：✓ 已完成 / ○ 待完成
  • 日记记录显示标题 + 内容摘要 + 心情 emoji
  • 再次点击同一卡片可收起详情
时间分组逻辑
  • 日视图：直接列出所有记录，按时间倒序
  • 周视图：按天分组（周一 9/1、周二 9/2...），每组可折叠
  • 月视图：按周分组（第1周、第2周...），每组可折叠
  • 年视图：按月分组（1月、2月...），每组可折叠
  • 分组标题显示记录条数，折叠/展开箭头指示状态
时间格式化
  • 日视图显示时:分（14:30）
  • 周视图显示星期 + 时:分（周一 14:30）
  • 月视图显示月/日 + 时:分（9/15 14:30）
  • 年视图显示月日（9月15日）
样式
  • 统计页头部新增"点击数字卡片可展开查看详细记录"提示
  • 可点击卡片右上角显示 ▸ 箭头标识
  • 分组卡片带边框和深色标题栏，折叠区域平滑过渡
  • 记录条目左对齐内容 + 右对齐时间，整洁易读
v2.9 待办优先级排序 · 长按编辑 交互升级

待办清单从按创建时间排序改为按重要程度排序，支持手动调整顺序。新增长按编辑功能，可以随时修改待办内容和优先级。

优先级排序
  • 待办自动按优先级排序：高 → 中 → 低
  • 同等优先级内按用户手动排列的顺序显示
  • 新添加的待办自动放到对应优先级组的末尾
长按编辑
  • 长按待办项 600ms 弹出编辑弹窗
  • 可修改待办内容、分类、优先级
  • 保存后立即重新排序，无需刷新
  • 触摸/鼠标都支持长按
手动排序
  • 每个待办项右侧有 ↑/↓ 按钮
  • 只能在同等优先级内调整顺序
  • 列表第一项的 ↑ 和最后一项的 ↓ 自动禁用
服务器稳定性
  • 所有 API 路由添加 try-catch 错误保护
  • MongoDB 连接失败时服务器不再崩溃
  • 新增全局错误处理器和进程级保护
  • 新增 /api/health 健康检查接口
v3.0 日记配图 · Cloudinary 云存储 重大版本升级

日记功能支持上传配图，图片存储在 Cloudinary 云端，自动压缩优化，不占用数据库空间。25GB 免费存储空间，约可存 6 万张图片。

日记配图
  • 写日记时可点"添加图片"从手机/电脑选图
  • 支持所有常见图片格式（JPG/PNG/HEIC/WebP）
  • 原图最大 10MB，上传后自动压缩
  • 日记列表显示图片缩略图
  • 点开日记可查看完整图片
  • 可随时删除已上传的图片
Cloudinary 云存储
  • 图片存储在 Cloudinary 云端，不占 MongoDB 空间
  • 服务器端自动压缩：宽度限制 1280px，质量自动优化
  • 自动转换为 WebP/AVIF 格式，体积更小
  • 25GB 免费存储空间，约存 6 万张图
  • 新增 POST /api/upload 和 POST /api/upload/delete 接口
依赖更新
  • 新增 cloudinary 依赖（云端图片管理）
  • 新增 multer 依赖（文件上传中间件）
  • express.json 限制提升至 15MB
界面优化
  • 计时器底栏图标从 ⏱ 改为 ⏰，大小统一
  • 删除每 10 秒自动拉取数据的定时器，减少卡顿
  • 计时器仅在计时页面可见时渲染
  • 使用指南弹窗 iframe 加载，无需跳转新页面
v3.1 日记录音 · 统计修复 功能完善

日记支持录音功能，录音存储在 Cloudinary 云端。修复统计页面待完成计数不包含跨天未完成待办的逻辑错误。

日记录音
  • 写日记时点"录音"按钮，浏览器请求麦克风权限
  • 录音最长 60 秒，文件最大 2MB（低采样率优化）
  • 录音存储在 Cloudinary 云端，不占 MongoDB 空间
  • 录音完成后显示音频播放器，可点播放
  • 日记列表有录音的显示 🎤 标志
  • 支持删除已录音
统计逻辑修复
  • 修复"日"统计页面待完成只统计当天创建的待办的问题
  • 新的逻辑：待完成 = 所有当前未完成、未归档的待办（跨天也算）
  • 已完成 = 在选定时间范围内完成的待办（按完成时间算）
  • 总数 = 已完成 + 待完成
  • 展开详情的"待完成"也同步修复
